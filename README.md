# 📱 Phone Finder Web Application

## Project Overview

This project is a simple Phone Finder web application developed using HTML, CSS, and JavaScript. The purpose of this application is to help users search for mobile phones and view their detailed information in an easy and interactive way. The interface is designed to be user-friendly so users can quickly find the phone they are looking for.

## Features

* Users can search phones dynamically using an API
* Phone cards display image, name, and brand
* Clicking on a phone card shows detailed information
* "Show All" button displays all available phones
* Clean and responsive user interface

## API Used

This project uses the Programming Hero Phone API to fetch phone data.

https://openapi.programming-hero.com/api/phones?search=oppo

## JavaScript Functionalities Used

The following JavaScript concepts and functionalities were used in this project:

* `fetch()` to retrieve phone data from API
* `onclick` event to handle user interactions
* `forEach()` to loop through phone results
* `innerHTML` to display dynamic content
* Template literals for inserting dynamic values
* DOM manipulation for updating UI
* Conditional rendering for displaying details

## How It Works

1. The user enters a phone name in the search bar.
2. When the search button is clicked, an API call is made.
3. Matching phones are displayed as cards.
4. The user can click on any card to see detailed phone information.
5. The "Show All" button reloads all available phones.
6. Users can easily navigate and search again.
